# 🛒 E-Commerce Platform

A full-stack e-commerce app with multi-role support (seller, employee, buyer).
## Live URLs

- **Frontend:** [https://ecommmm-psi.vercel.app](https://ecommmm-psi.vercel.app)
- **Backend API:** [https://ecommmm-gsre.onrender.com](https://ecommmm-gsre.onrender.com)
  
##  Features

- **Seller / Employee** – manage products, view orders, update status, invite employees, dashboard stats.
- **Buyer** – browse & search products, add to cart, checkout (mock payment), order history.
- JWT authentication, role-based access, persistent login.

##  Tech Stack

- **Frontend:** React, TypeScript, Vite, Redux Toolkit, Material‑UI, Tailwind CSS, Axios.
- **Backend:** Node.js, Express, TypeScript, MongoDB, Mongoose, JWT, bcryptjs, Zod.
